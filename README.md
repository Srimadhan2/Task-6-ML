# 🌸 Task 6 - K-Nearest Neighbors (KNN) Classification

## 🎯 Objective
To implement the **K-Nearest Neighbors (KNN)** algorithm using **Scikit-learn** for a classification problem and understand how K and feature scaling affect performance.

---

## 📁 Dataset
- **Dataset Used**: Iris dataset from `sklearn.datasets`
- **Features**: Sepal Length, Sepal Width, Petal Length, Petal Width
- **Target**: Iris-setosa, Iris-versicolor, Iris-virginica (multi-class classification)

---

## 🛠 Tools & Libraries
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib & Seaborn (for visualization)

4. **Normalized features** using `StandardScaler` to improve distance-based KNN accuracy.
5. **Trained KNN models** with different values of K (1 to 10).
6. **Evaluated each model** using accuracy scores.
7. **Plotted Accuracy vs K** to identify the best-performing K.
8. **Generated a confusion matrix** for the best K value to assess classification performance.
